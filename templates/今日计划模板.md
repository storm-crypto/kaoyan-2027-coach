# 今日计划模板

写入方式：AI 读取 `get_plan_context.py` 返回的候选池后生成正文，用 `plan_ops.py --content-file 文件` 先归档再写入 `周计划/_今日计划.md`。任务使用原生复选框；同日重排保留已完成项及其备注。`build_daily_plan.py --write` 仅保存候选 JSON。

```markdown
# 今日计划：{today}

## 今日概览
- **可用时长**：{available_hours} 小时
- **到期复习**：{due_summary}
- **主攻科目**：{focus_subjects}

{textbook_section}
## 任务清单
{tasks}

## 排计划依据
{planning_reasons}

## 收尾提醒
{closing_notes}
```
