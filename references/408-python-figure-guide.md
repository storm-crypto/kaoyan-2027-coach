# 408 Python 讲解图

需要位置、比例、对齐或分步高亮时使用本参考；仅有少量节点关系或事件先后，用 [Mermaid](mermaid-figure-guide.md)；精确数据与计算核对保留 Markdown 表格。先读 [Python 共用调用与输出约定](python-figure-guide.md)，沿用 `fig`、SVG / 源码 / PNG 预览与 `figure_arg` 链路，无须新渲染器。

## 选骨架

从 [408 骨架集](../templates/408_figure_examples.py) 复制相关函数，或改 `EXAMPLE` 后运行。内含示例条件，归档前替换为本题已知量和已推导的状态，不把示例数据当题目事实。

六类骨架是已运行验证的起点，**不是配图白名单，也不限制其它题型**。没有专用骨架时，按本题关系、状态变化和比例要求，组合节点/连线、格子/指针、字段条或时间区间生成新的绘图源码，再走同一预览与归档链路；不得因为没有现成示例而省略必要的图。新题型的图仍须逐题核对，不能把六类示例的验证结果当作所有图都已验证。

| EXAMPLE | 解决什么 | 本题需要明确的数据 |
|---|---|---|
| `tree` | LL 失衡与右旋前后；可改成其它旋转/分裂 | 每阶段根、左右孩子、节点身份；检查中序与结构约束 |
| `linked_list` | 单链表逆置一次迭代的保存、改指向、前移 | 每阶段 next、prev、cur、nxt；固定节点位置，箭头从指针域指向目标 |
| `cache` | 地址位段与直接映射路径 | 地址位数、行/组数、块大小、具体地址及映射规则；示例同一组条件贯穿位段和映射 |
| `pipeline` | 指令阶段重叠的时空网格 | 每指令每周期阶段、停顿原因、转发/访存等硬件假设；示例仅独立指令无停顿 |
| `scheduling` | 按真实时长的 CPU 甘特图 | 到达、服务、算法、同到达规则、抢占时刻、切换开销；计算表另写正文 |
| `network` | 首/末比特的发送与到达 | 长度、速率、传播时延与单位；示例没有 ACK，不自动补确认或排队 |

例：将源码中的 `EXAMPLE` 改为 `pipeline`，并替换状态数组后：

```sh
python3 scripts/create_figure.py "$KAOYAN_OBSIDIAN_ROOT" \
  --kind python --question-id qid-xxxxxxxxxxxx --slug 流水线时空 \
  --caption '图1：各指令的阶段重叠与停顿位置' --width 640 \
  --source-file /absolute/path/to/figure.py
```

`scripts/cs_figure_style.py` 提供可复用基础件：

- `field_strip(ax, fields, total_bits)`：字段按高位到低位传入，宽度直接等于位宽；拒绝非正整数或位宽和不符，自动标出位序和求和。字段太窄时标注移到外部，不缩小文字。
- `timeline(ax, segments)`：区间为 `(名称, 开始, 结束)`，宽度等于时长，拒绝零/负时长及单资源重叠。传入完整时间线，空闲/切换区间显式标出；多核每核独立一行。
- `binary_tree(ax, children, root, active=())`：左右孩子明确传入，中序序号固定横坐标，L/R 写在边上；拒绝环与共享孩子。旋转时节点可移动但身份、子树归属不能改变，前后画布保持一致。

## 其它题型怎么改

- **B/B+ 树、堆、图算法**：节点框或数组格固定布局，仅高亮本步分裂/交换/选边；各步沿用同一组节点 ID、图坐标和边权。B+ 树区分内部索引与叶子链，不能直接套二叉树函数。
- **栈 / 队列 / 循环队列**：格子标下标，变量标当前指向；操作前后保持格子位置，明确栈顶、队头、队尾指向元素还是下一空位。环回用方向箭头表示；判空/判满及是否牺牲一个单元按题给定义，不能混用约定。
- **KMP / 排序 / 哈希**：用矩形格代替普通文本序列；KMP 对齐主串和模式串，标指针、失配位置、回退依据，说明 next 约定；哈希标槽位、探测方向及次数；排序突出当前比较/移动，完整数值另表核对。
- **Cache / 页表 / TLB**：位段颜色对应查找路径；地址字段与索引值从同一地址计算，字节/字寻址不能混用；组相联标“组”及组内多路，不能把直接映射示例原样套用。
- **流水线**：停顿用有文字的灰格，依赖用箭头并标 RAW 等原因。时钟周期等宽；非等时长异步阶段则按时间绘制。表格必须包含最后一条指令完成阶段，不能截断末周期。
- **磁盘 / 内存 / 页面置换**：磁盘横轴磁道、纵轴访问序号或反过来并明确标出，序号不冒充实际时间；SCAN/C-SCAN 的端点与回卷是否计入移动按题意。内存块按地址比例画，页框状态按访问次数对齐，受害页高亮，旁边保留缺页计数。
- **同步互斥 / 文件索引**：执行交错按进程分列或分行，标 P/V、等待/唤醒及状态变化，数值与伪代码对应；文件索引分层画指针、索引块和数据块，高亮本次查询路径，访问次数按题给缓存条件核对。简单关系与事件先后可直接用 Mermaid。
- **TCP / 滑动窗口**：序号格标已确认、已发送未确认、可发送范围及窗口边界，说明按字节还是报文编号、区间开闭；ACK 推进与超时事件分步画。只讨论报文先后可用 Mermaid，涉及传播、超时数值时用统一时间轴，所有斜线端点对应实际收发时刻。
- **CSMA/CD**：明确站点、传播时延、帧发送区间和碰撞检测事件；传播斜线与检测时刻按题目计算，不根据画面猜结论。
- **数据通路 / 存储器扩展**：简单局部流向用 Mermaid；涉及总线、复用器、芯片连线位置时用 Python。保留题给必要硬件结构，淡化无关连线，高亮当前节拍路径；不要新增题面未给出的通路。数据线、地址线、控制线用标签或线型区分。

## 生成后核对

- 图和正文共用状态/地址/时间数据；字段求和、地址重组、周转时间、完成周期、发送/到达时间能相互核对。程序执行成功不等于这些条件自动正确。
- 箭头必须有明确含义：孩子关系、指针、数据传送、事件消息不可混用；方向、序号和控制信号与正文一致。单总线按硬件检查驱动源冲突及并发接收限制，不能按箭头数量推断节拍。
- 每步突出一个新动作，未变化部分保持相对布局；颜色之外还用文字/线型区分。阶段标题可读，目标宽度下没有重叠、裁切或过小的格中文字。
- 先看 `preview_path`，再传 `figure_arg` 进入详解区。表格保留可编辑文本，避免把所有数据压成截图；复习先独立作答再展示辅助图。
