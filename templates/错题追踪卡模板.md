# 错题追踪卡模板

## Obsidian 错题追踪卡格式

文件命名规则：`错题本/[科目]/[章节]/[考点关键词]-[来源简称]-[question_id].md`
例：`错题本/数学一/多元积分/二重积分极坐标-900题-qid-a1b2c3d4e5f6.md`

**`question_id` 是主键**。新题先用 `generate_question_id.py` 生成 `question_id`，旧题识别优先按 `question_id` 精确匹配；关键词只用于兼容旧卡和人工消歧。

```markdown
---
source:
question_id:
topic:
error_tags: []
first_wrong_at: YYYY-MM-DD
last_review_at: YYYY-MM-DD
wrong_count: 1
status: 不会
next_review: YYYY-MM-DD
review_interval: 1
ease_factor: 2.50
---

#subject/math1 #topic/多元积分 #status/不会 #source/900题

## [考点关键词] — [来源简称] — [question_id]

### 题目
- [尽量保留完整题面原文；如果有 A/B/C/D 选项，直接连续写在这里，不再单独拆区块]

### 图示
- 可选区块；只在命中配图白名单时出现（详见 SKILL.md「配图规则（SVG 矢量图）」）
- 由 `create_figure.py` 落盘、`create_wrong_card.py --figure` 写入，位置固定在「突破口小节」之后

### 错题详解（按科目模板展开）
- 数学一：`考点判断 / 第一步怎么想到 / 规范解法 / 错因定位 / 易错点 / 下次怎么做 / 检查你是否真的懂了`
- 408：`考点定位 / 题干突破口 / 选项逐个辨析 / 双轨解释 / 干扰项陷阱 / 知识网络串联 / 记忆钩子 / 检查你是否真的懂了`
- 其他科目：至少保留 `错误原因 / 正确思路 / 易错点`

### 历史记录
- YYYY-MM-DD - 不会 / 半会 / 会 - [一句话简评]
```

## 数学一详解结构化示例

排版目标：`考点判断` 逐字段单独成行（**禁止**把多个字段挤进一行），`规范解法` 用短段落 + 独立块公式（**不要**把整段推导压成一个长 bullet）。`create_wrong_card.py` 会拒绝拥挤格式。

```markdown
### 考点判断
- 题型：反三角函数复合不定积分
- 章节：不定积分的计算
- 考点：反三角整体换元、三角恒等变形、分部积分
- 难度：中等
- 考频：常见模型
- 突破口：令 $t=\arctan x$，把代数结构转成三角结构

### 第一步怎么想到
- 先看：被积函数里有 $\arctan x$，分母又有 $1+x^2$
- 再问：整体换元能不能把代数结构约掉
- 触发：令 $t=\arctan x$，则 $1+x^2$ 与 $dx$ 中的 $\sec^2t$ 抵消

### 图示
![[错题本/_附图/qid-a1b2c3d4e5f6/qid-a1b2c3d4e5f6-01-积分区域.svg|480]]
- 图1：原积分区域 D 与「先 y 后 x」的条带方向

### 规范解法
先令 $t=\arctan x$，则 $x=\tan t$，$dx=\sec^2t\,dt$，原式降维：

$$
I=\int t\cot^2t\,dt.
$$

再用 $\cot^2t=\csc^2t-1$ 拆开，逐项分部积分。

### 错因定位
- 根因：没有先比较「直接分部」和「整体换元」的复杂度
- 误触发：一看到反三角就硬上分部积分
- 正确触发：见 $\arctan x$ 配 $1+x^2$，先整体换元

### 下次怎么做
- 看到：反三角函数乘复杂有理式
- 先做：判断整体换元能否约掉代数结构
- 再做：换元后见三角平方，先恒等变形再分部
```

## 间隔复习规则

每张错题卡有 `next_review`（下次复习日期）和 `review_interval`（当前间隔天数）。

**新建时：** `next_review` = 明天，`review_interval` = 1

**复习后根据结果调整（改进版 SRS，含 ease_factor）：**
| 结果 | interval 变化 | ease_factor 变化 |
|------|--------------|-----------------|
| 不会 | 重置为 1 天 | ease × 0.8（下限 1.3） |
| 半会 | interval × 1.2（至少 +1 天） | 不变 |
| 会 | interval × ease_factor（上限 90 天） | ease + 0.1 |

`next_review` = 今天 + 新 interval，`ease_factor` 默认 2.50

**到期未复习的题自动降级：** 超过 `next_review` 7 天以上未复习的卡，`review_interval` 重置为 1。

## 模板使用规则

- 第一次出现该题时，先运行 `python3 scripts/generate_question_id.py [来源] [题号/题干摘要...]` 生成 `question_id`，再新建完整错题追踪卡。
- 新建卡片时，`### 题目` 必填；如果是选择题、判断题或带备选项的题，也直接把选项并入 `### 题目`，不要再单独拆区块。
- **题面输入二选一**：`--question` 已含完整题面（含 A/B/C/D）时，**不要**再传 `--option/--options` 同一组选项；选项要么写进 `--question`，要么走 `--option/--options`，禁止同一组选项两边都传（脚本会拒绝落盘）。
- 数学一和 408 的新卡，详解区优先按对应参考模板落成固定小节，不要只写成泛化的三段式摘要。
- 新卡文件名必须带上 `question_id`，frontmatter 里也必须写入同一个 `question_id`。
- 复习同一道题时，不新建平行条目；优先按 `question_id` 定位卡片，更新 `last_review_at`、`wrong_count`、`status`、`next_review`、`review_interval`，在"历史记录"中追加一条新记录。
- 如果旧卡是历史遗留卡、还没有 `question_id`，首次命中后应立即回填 `question_id`，并把文件重命名为带 `question_id` 的规范文件名，完成迁移。
- 日期格式：`YYYY-MM-DD`。
- 同类错因但不是同一道题，用 `error_tags` 关联，不强制合并。
- `status` 固定为 `不会 / 半会 / 会` 三档。
- 正文解释里的短公式默认用行内公式 `$...$`；只有独立推导式、变形链、最终结论才用 `$$...$$`。
- **配图是可选区块**：只在命中白名单（积分区域、函数作图、Cache 位段、时序图等）时才有 `### 图示`；没图的卡不留空壳小节。
- 图必须走 `create_figure.py` → `--figure` 落盘，禁止手写 `![[...]]`；说明统一写成 `图N：一句话`，并在 `规范解法` 里用「见图1」引用，图文才对得上。
- 题面本来就带的图走 `--question-figure`（落在题面末尾）；解题辅助图走 `--figure`（落在详解区），否则 `/review` 一打开卡片就泄题。
- 文件名、YAML frontmatter、正文 tag 里不要放数学公式，只保留纯文本。

## Tags 用法

- **正文 tag**：只保留 `#subject/...`、`#topic/...`、`#status/...`、`#source/...`，不超过 5 个
- **YAML `error_tags`**：保存完整错因描述，用于跨题搜索同类错误
