## bullet 结构化约定（让周/月复盘能真正汇总）

「学到了什么」「卡壳与挣扎」两段的每条 bullet **推荐**写成：

```
类型::内容 (科目·子科目·chN) 附加::值
```

- **类型**：教材 / 学习 / 卡点 / 总结 / 试错（保留集）。可省略，省略时不参与按类型聚合
- **内容**：禁止"今天"、"若干"、"一些"。教材进度直接写 `推进到 pXX` 或 `pXX → pYY`
- **章节标签**：放在末尾的小括号里，三段以 `·` 分隔。例：`(数学一·高数·ch2)` / `(408·DS·ch3)` / `(英语一·ch1)`
- **附加信息**：信心、下次怎么验证、关联错题号等，写在章节标签之后

复盘脚本会按 `(科目, 子科目, 章节号)` 三元键聚类。**没有章节标签的 bullet 不参与按章聚合**，只按日期堆叠。

## /progress 推荐输入格式

**核心理念**：用户的笔记和错题都在 Obsidian 里沉淀了，教练会主动扫今日 `知识笔记/` + `错题本/`，从沉淀派生「学到了什么」和「卡壳与挣扎」段。用户只需告诉教练 Obsidian 看不到的信息。

**推荐写法（极简，≤ 30 字）**：

```text
/progress
时长 9h
李林高数推到 p58
ch2 课后题 22/28
明天开始 ch3
```

**最少输入 4 项**：

- 学习时长（最重要，文件系统抓不到）
- 教材推进（如果当天笔记/错题里没体现到页码）
- 训练成绩（如有）
- 明天计划（可选）

**教练流程（hard rule）**：

1. 先 Read `知识笔记/` 下 frontmatter `created` 是今日的笔记，提取标题 + 章节归属 → `--learned "学习::笔记标题 (科目·子科目·chN)"`
2. 再 Read `错题本/` 下 frontmatter `first_wrong_at` 是今日的卡，读 topic + `### 正确思路` → `--blocker "卡点::topic (...)"` + `--learned "总结::解法套路 (...)"`
3. 扫每张错题的 `### 历史记录`，今日条目升级到「会」的进 `--mastered`
4. 把用户提供的"时长/教材/成绩/明天"合并进 CLI 参数
5. 调 `log_progress.py`

**禁止**：教练不能反过来问用户"今天学了什么"这种本可以扫笔记得出的问题；不能照搬"今天xxx"或"若干xxx"这类模糊表达。

老的"按 6 项模板填"也兼容，但不再是推荐路径——前两项你写得越细，反而越容易和 Obsidian 沉淀重复：

```text
/progress
1. 今天学了什么：
2. 卡住了什么：
3. 做了什么题 / 测试：
4. 如果有成绩：按"科目 / 类型 / 来源 / 得分 / 满分 / 备注"给出
5. 状态怎么样：
6. 学了多久：
```
