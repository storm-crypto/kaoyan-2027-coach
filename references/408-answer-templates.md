# 408 综合题答题模板

仅在处理 408 **综合应用题**（大题、多问题、计算题、算法设计题）时读取本文件；单选题不加载。选择题的答疑结构见 `408-coaching.md`。

综合题需要呈现可核对的解答过程。下面的题型模板规定必要过程与要素；按题面条件使用，不虚构硬件、评分分值或算法要求。归档时这些内容进入“暴力扫雷”的逐问解答，讲解与自测分工见 [408 错题讲解与归档](408-coaching.md)。

图表按理解难点选型：位置/比例/对齐/过程高亮见 [408 Python 配图参考](408-python-figure-guide.md)，简单关系与事件先后见 [Mermaid 与表格参考](mermaid-figure-guide.md)。图走 `create_figure.py --kind python|mermaid` 落进图示区，Python 图先检查预览；表格直接写进解析文本。

**关于泄题**：综合题的表格和流向链本身就是解题过程，允许放进图示区。大题复习本来就是重做过程，图示与原题解析直接展示；`/review` 先独立完成原题，再向下查看图示与解析。

## 综合题解答的组织方式

1. **【题型定位】**：属于下面哪个模板，考的是哪个过程
2. **【拆问】**：每一小问依赖哪个前置量，先做哪问
3. **【按模板输出】**：下面对应模板的固定结构
4. **【关键得分步骤】**：点出容易漏写的必要过程；官方细则标来源；仅知总分时可列训练估分并标明非官方且合计一致，连总分也未知时只列关键词，不凑条数
5. **【理解检查】**：针对关键动作改变条件提问，不给答案；归档放到“变式拷问”，只保留一道完整题面

## 数据结构

### DS-1 算法设计题（41 题）

保留下面四项，按实际算法展开：

1. **【基本设计思想】**：自然语言，说清用什么结构、为什么、复杂度来源在哪一步
2. **【C/C++ 代码】**：语义化变量名，每个关键分支一行注释，边界条件显式处理
3. **【正确性说明】**：说明不变量或递推关系、终止条件及结果为何满足题意。
4. **【复杂度分析】**：时间与空间各给阶数并一句话推导（「外层 n 次、内层最多 log n 次」）

写代码前先问一句：题目要求的时间复杂度是否限定了方法（O(n) 排除排序、O(1) 空间排除辅助数组）。

### DS-2 过程模拟题（排序 / 哈希 / Huffman / KMP / 遍历）

固定输出：**逐步快照表** + **最终结论行**。指针、失配、探测或移动过程是卡点时，额外用 Python 对齐格子分步展示，表格仍保留精确值。

| 题型 | 表格列 | 结论行 |
|---|---|---|
| 排序每趟 | 趟数、数组快照（本趟移动元素加粗）、本趟动作 | 总趟数、比较次数或稳定性判断 |
| 哈希插入 | 关键字、哈希值、冲突处理后的地址、探测次数 | 平均查找长度（成功 / 失败分开算） |
| Huffman | 合并轮次、当前森林的权值集合、新节点权值 | 带权路径长度 WPL，编码表 |
| KMP | j、模式串、next、nextval | 匹配失败时的回退位置 |
| 图遍历 | 访问序号、当前顶点、栈或队列状态 | 遍历序列 |

### DS-3 结构操作题（BST / AVL / B 树 / 堆）

- **操作前后按需分步**：优先 Python，固定节点身份和未变化子树的相对布局，高亮本步变化，二叉树边标 L/R；简单静态关系可用 Mermaid
- 中间每一步用一行文字：「插入 45 后 30 的平衡因子变为 +2，对 30 做 LR 旋转」
- B 树分裂题：写出分裂前节点、上提的关键字、分裂后左右两个节点

## 计算机组成原理

### CO-1 数据通路与微操作（指令执行流程、控制信号）

保留解释本指令所必需的题给结构，高亮当前路径，淡化无关部分，不凭空新增通路。过程题配合以下图表：

1. **【局部数据路径图】**：简单链用 Mermaid；需要保留总线/复用器位置时用 Python。按节拍或取指/执行阶段分步，标控制信号与节拍，不按连线数计算微操作数。
2. **【节拍与微操作对照表】**：四列固定：

| 时钟节拍 | 微操作（数据流向） | 有效控制信号（=1） | 通俗解释 |
|:---:|:---|:---|:---|

对照表校验：按题给硬件检查总线驱动冲突、接收限制与数据依赖；并发微操作按真实节拍分组。PC 自增的时机由题给通路和访存时序确定，不强行和主存读合并。

微程序题再补一行：微指令字段格式（操作控制 / 顺序控制）与本条微指令的取值。

### CO-2 Cache / 虚存地址映射计算

必须输出：

1. **【位段划分表】** + 位宽求和校验（`19 + 7 + 6 = 32 ✓`）
2. 遇到具体地址：**二进制切分行** → 各字段十进制值 → 命中判断
3. 命中率、平均访问时间的计算链，每一步带单位

组相联题先算「组数 = 行数 / 路数」，直接映射当成 1 路，全相联没有组号位段。需要看清地址切分与块/组映射时，按 `408-python-figure-guide.md` 配 Python 比例字段条与对应图，图表使用同一数据。

### CO-3 指令格式与扩展操作码

- **【指令格式位段表】**：操作码、寻址方式、地址字段各多少位，求和校验
- **【编码数量校验】**：扩展操作码题写出每类指令占用的编码区间与剩余编码数，如「3 地址指令 15 条，占 0000 到 1110，剩 1111 前缀扩展」
- 寻址范围题写出「地址字段位数 → 寻址范围 → 是否需要偏移或段基址」

### CO-4 流水线时空图与冒险

过程优先 Python 彩色网格，以下时空表保留精确状态核对。周期等宽，末条完成阶段不能截断，停顿注明原因。

- **【时空表】**：横轴周期、纵轴指令，段名填格，停顿格加粗并注明冒险类型（RAW / WAR / WAW / 控制 / 结构）
- **【合计行】**：总周期数、吞吐率、加速比的算式
- 转发和分支预测题：画「无优化」「有优化」两张表对比

### CO-5 数据表示与运算（定点 / 浮点 / 补码）

**逐步表**，每一步只做一个动作：

| 步骤 | 动作 | 符号 | 阶码 | 尾数 | 说明 |
|:---:|:---|:---:|:---:|:---|:---|

浮点加减固定五步：对阶、尾数运算、规格化、舍入、溢出判断。IEEE 754 题先写出偏置值和隐藏位。补码乘除写出每一步部分积和移位。

### CO-6 C 语言与汇编对照（近年高频）

| C 语句 | 汇编 | 作用 | 栈帧 / 寄存器变化 |
|:---|:---|:---|:---|

必须回答：局部变量在栈帧哪个位置、函数调用时返回地址和参数怎么压栈、`int` 与 `unsigned` 比较为什么结果不同。

### CO-7 总线、中断、DMA 传输率

**计算链**每一步带单位：

- 数据传输率 = 总线宽度 × 总线频率 / 每次传输周期数
- 中断方式 CPU 占用率 = 中断处理时间 / 数据到达间隔
- DMA 方式：只有初始化和结束时中断，占用率按块算

必须说明本题是「字节多路」还是「块传送」，这决定占用率算法。

## 操作系统

### OS-1 PV 操作同步互斥

必须四步：

1. **【模型定性】**：归属生产者消费者 / 读者写者 / 哲学家 / 理发师，或它们的变形
2. **【信号量定义表】**：

| 信号量 | 初值 | 物理意义 |
|:---|:---:|:---|

3. **【并发伪代码】**：每个进程一段，P/V 成对标注；**互斥 P 必须紧贴在同步 P 之后**，否则死锁
4. **【防死锁说明】**：一句话解释为什么 P 的顺序不会死锁

### OS-2 地址转换（页式 / 段页式 / TLB）

- **【地址位段表】**：逻辑地址的页号与页内偏移各多少位，求和校验
- **【逐步转换表】**：

| 步骤 | 输入 | 查什么 | 得到 | 说明 |
|:---:|:---|:---|:---|:---|

- 多级页表题写出「一级页号、二级页号、偏移」三段切分和每级页表的大小
- TLB + Cache 联合题按 2.6 的 Mermaid 翻译链画一张图

### OS-3 处理机调度

- **【比例甘特图 + 时间核对表】**：Python 图中运行区间宽度对应时长；表保留时间段与运行进程，空闲、切换开销按题意显式标出
- **【周转时间表】**：到达、服务、完成、周转、带权周转，合计行给两个平均值
- 抢占式算法在甘特表里显式标出「被抢占」的时刻和原因

### OS-4 死锁与银行家算法

- **【资源矩阵表】**：Max、Allocation、Need、Available
- **【安全性检验表】**：

| 轮次 | Work | 检查进程 | Need ≤ Work? | 执行后 Work |
|:---:|:---|:---|:---:|:---|

- 结论行给安全序列或「无安全序列」；请求判断题先做「请求 ≤ Need 且 ≤ Available」两步预检

### OS-5 页面置换与缺页

- **【逐次访问表】**（见 mermaid-figure-guide 3.8）：访问页、各帧状态、是否缺页
- 合计行：缺页次数、缺页率
- LRU 题写清「最近最久」是按时间戳还是栈；Clock 题画指针位置

### OS-6 文件系统与索引

- **【索引层级表】**：直接 / 一级 / 二级 / 三级各能寻址多少块，合计最大文件大小
- 给定偏移量时写出「偏移 / 块大小 → 逻辑块号 → 落在哪一级 → 访问几次磁盘」
- FAT、位示图题写出每项占多少位和表的总大小

### OS-7 磁盘调度与 I/O

- **【轨迹表】**：序号、磁道、移动距离，合计总寻道和平均寻道
- 访问时间题分三段：寻道 + 旋转延迟（平均半圈）+ 传输，每段带单位

## 计算机网络

### NET-1 跨网段通信与协议封装

- **【拓扑简图】**（Mermaid `graph LR`）：只放接口 IP 与 MAC
- **【逐跳封装表】**：跳步、当前设备、报文类型、源/目的 IP、源/目的 MAC、机制说明
- 结论行：IP 端到端不变，MAC 逐跳更换；ARP 在哪一跳触发

### NET-2 TCP 拥塞控制

- **【RTT 演进表】**：RTT 轮次、cwnd、ssthresh、阶段、触发事件
- 转折点加粗：进入拥塞避免、超时、快重传
- 结论行区分 Tahoe 与 Reno 的处理差异（超时都回 1，快重传 Reno 减半）

### NET-3 子网划分与路由

- **【子网表】**：

| 子网 | 网络号 | 掩码 | 广播地址 | 可用范围 | 可用主机数 |
|:---|:---|:---|:---|:---|:---:|

- 可用主机数校验：`2^h - 2`
- 路由表题：目的网络、掩码、下一跳、接口；**最长前缀匹配**的比较过程逐条写出
- CIDR 聚合写出共同前缀的二进制对齐

### NET-4 可靠传输与信道利用率

- **【时序图】**：只看事件先后可用 Mermaid；涉及发送/传播/超时数值时用 Python 统一时间轴，窗口移动用对齐序号格分步展示，注明单位与边界
- **【计算链】**：发送时延 = 帧长 / 带宽，传播时延 = 距离 / 速率，利用率 = 发送时延 / (发送时延 + 2 × 传播时延)
- 滑动窗口题先算「窗口大小 ≥ 带宽时延积对应的帧数」再判断能否满速

### NET-5 报文字段解析（抓包题）

| 偏移 | 字段 | 值（十六进制） | 含义 |
|:---:|:---|:---|:---|

必须回答：这是哪一层的哪个协议、关键标志位（SYN/ACK/FIN、DF/MF）的值、长度字段与实际长度是否一致。

### NET-6 CSMA/CD 与数据链路层

- 争用期 2τ、最短帧长 = 2τ × 带宽 的计算链
- 检测到冲突的时刻、退避后的重发时刻用 Python 比例时间轴给出，表格核对数值；示意图需明确说明非按比例
