# 复现 README 工作台截图

演示库使用**虚构数据**：6 张数学一 / 408 题卡、3 个元技能簇、四科知识地图、今日与周计划、学习日志及成绩。它由仓库当前的工作台生成器渲染，没有单独维护一套截图专用 UI，也不读取个人学习库。

在仓库根目录执行：

```bash
python3 docs/demo/build_demo.py /tmp/kaoyan-coach-demo
```

脚本必须显式指定输出目录，并拒绝非空目录和符号链接；再次运行时换一个新目录。输出 JSON 会给出工作台与统计页的绝对路径。用浏览器打开输出目录中的 `可视化面板/index.html`，即可切换「今天」「复习」「知识地图」「元技能」「进展与复盘」。

业务数据固定在 **2026-11-11**；生成时间显示实际运行时间。其他日期打开时，页面会正常提示这是旧快照，不代表构建失败。原卡与计划链接使用 Obsidian 协议，只有把该演示目录作为 vault 打开后才能跳转；截图和浏览工作台不依赖 Obsidian。

首页图片保存在：

- `docs/images/workbench-today.png`：今日任务与本周主线。
- `docs/images/workbench-review.png`：到期复习与排序依据。
- `docs/images/workbench-metaskills.png`：方法步骤、适用边界与题卡历史。

更新配图时，重新生成演示库、打开真实页面并截图即可。不要把真实个人成绩、姓名、院校目标或私人笔记带入公开配图。
