# 408 章节体系：《老汤讲408》一轮课程详细大纲

> **本文件是 408 章节编号与节名的唯一事实源。** `知识地图/408.md` 的行、`/wrong 408 --chapter` 的叶子章节、`/grill` 的 `【可映射考点】`、学习日志里的 `(408·DS·chN)` 标签，章号和节名都以这里为准。
>
> 来源：老汤讲 408 四科「一轮课程详细大纲」思维导图（数据结构 / 计算机组成原理 / 操作系统 / 计算机网络），2026-09 提取。课时编号是老汤课程目录里的序号；`知识笔记/408/` 里的笔记文件名也用这个编号做前缀（例：`知识笔记/408/计组/ch3 存储器/37 静态随机存取存储器 SRAM.md`）。

## 老汤顺序和王道 / 考纲不一样的地方

- **计组**：第二章就是总线，第三章主存储器（含 Cache），第四章才是数据的表示与运算；指令系统按 MIPS → X86-64 → 指令格式设计的顺序讲。
- **操作系统**：先讲文件系统（第二章）和 I/O 设备管理（第三章），再讲内存管理（第四章）与虚拟内存（第五章），进程 / 调度 / 互斥同步放在六、七、八章。
- **数据结构**：KMP 单独成章（第七章），堆及其应用是 2025 新增考点、挂在树这一章下。
- **计网**：路由选择协议独立成第六章，放在运输层之后；无线网络与移动网络是第八章。
- 每科最后一章（严蔚敏 / 袁春风 / 汤小丹 / 谢希仁教材重点梳理）是复习索引，不是知识点，**不进知识地图**。

- 节号 `NN.MM` 与知识地图叶子行 `NN.MM 节名` 完全一致，`--chapter` 传节名或别名都能命中（别名表见 `scripts/wrong_card_path_map.py` 的 `_408_OUTLINE`）。
